# 家計帳アプリ セットアップ手順

お金は一切かかりません。Googleスプレッドシート(データ保存)＋GitHub Pages(公開)の無料の組み合わせです。

## 1. Googleスプレッドシート側の準備

1. https://sheets.new でスプレッドシートを新規作成
2. メニューの「拡張機能」→「Apps Script」を開く
3. 中身を全部消して、同梱の `AppsScript_Code.gs` の内容を貼り付ける
4. 上部の関数選択で `setup` を選び、▶(実行)をクリック
   - 初回は権限確認が出るので「許可」する
5. スプレッドシートに戻り、「Entries」「Rules」「Budgets」「Config」の4シートができていればOK
6. Apps Scriptの画面右上「デプロイ」→「新しいデプロイ」
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」をクリック
7. 発行された **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec`)をコピーしておく

> このURLを知っていれば誰でもデータを読み書きできます。他人に教えないでください。

## 2. これまでの家計簿データを取り込む

1. スプレッドシートの「Entries」シートを開く
2. 同梱の `entries_import.csv` の中身(1行目のヘッダーは除く、2行目から)をコピー
3. 「Entries」シートのA2セルに貼り付け(すでにあるヘッダー行はそのまま)

これで2026年8月〜2029年12月分の収支データ(434件)がすべて入ります。

## 3. アプリの動作確認(パソコン)

Node.js (https://nodejs.org) がインストールされていることを確認したら、このフォルダで:

```bash
npm install
npm run dev
```

ブラウザで表示されたURL(http://localhost:5173 など)を開き、手順1でコピーした
ウェブアプリのURLを入力欄に貼り付けて「保存して接続」。データが表示されればOKです。

## 4. GitHub Pagesに公開する(スマホからも使えるようにする)

1. GitHub (https://github.com) の無料アカウントを作る(すでにあれば不要)
2. 新しいリポジトリを作成する。名前は何でもよいが、`vite.config.js` の
   `base: "/kakeicho/"` の部分をリポジトリ名に合わせて書き換える
   (例: リポジトリ名が `my-ledger` なら `base: "/my-ledger/"`)
3. このフォルダの中身を、作ったリポジトリにアップロードする
   (GitHub Desktop を使うのが一番簡単です: https://desktop.github.com)
4. ターミナルでこのフォルダに移動し:
   ```bash
   npm install
   npm run build
   npm run deploy
   ```
5. GitHubのリポジトリ画面 →「Settings」→「Pages」で、
   Source が `gh-pages` ブランチになっていることを確認
6. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになります

## 5. スマホで使う

1. スマホのブラウザ(Safari / Chrome)で上記URLを開く
2. 初回だけ、手順1でコピーしたApps ScriptのURLを設定画面で貼り付ける
3. 共有メニューから「ホーム画面に追加」すると、アプリのように起動できます

## 主な機能

- 収支入力(絞り込み検索・複数選択での一括削除/一括金額変更つき)
- サマリー(起点残高込みの累計貯金額推移、期間指定表示)
- 遊び代(月ごとの予算管理、カード引き落とし予定の自動集計)
- 貯金シミュレーション(定期予定・単発予定をまとめて登録し、将来の貯金額を試算)
- シナリオ比較(基本給・残業・昇給率を変えた場合の年収試算)

## トラブルシューティング

- **「通信エラー」と出る**: Apps ScriptのURLが正しいか、末尾が `/exec` になっているか確認してください。
- **デプロイ後にコードを直した**: Apps Scriptは「デプロイを管理」→ 鉛筆アイコン →「新しいバージョン」を選ばないと変更が反映されません。
- **カード払いの引き落とし日がずれている**: 個別に「収支入力」で該当行を探し、金額をクリックして修正するか、削除して入れ直してください。
